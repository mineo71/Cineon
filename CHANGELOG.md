# Changelog

Each release's section here becomes its notes on GitHub and in Cineon's update window.
Versions follow [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-07

### Added
- **Cineon for Windows**: the same app on Windows 10 and 11, x64 and ARM, built natively with WinUI 3
  and WebView2. Same screens and features, and the same data formats, so a profile folder copied
  from a Mac opens on Windows. Install with `Cineon.App-win-x64-Setup.exe` (or `-win-arm64-`); it
  updates itself from these releases, like the Mac app.

### Fixed
- An episode no longer rolls on to the next one after you've said no, when an old countdown was
  still running in the page.

## [1.0.1] - 2026-11-06

### Fixed
- A crash when a Legend-stage pet twinkled at the very end of its animation.

## [1.0.0] - 2026-11-06

First public release.

### Added
- **Watching across sites**: Cineon remembers what you watched, where, and how far you got, and
  jumps back to your place. Shields block ads, pop-ups, redirects and click traps.
- **Library and ratings**: a library built from what you watch, with lists, filters, ratings out of
  ten and Rate mode. Import history and bookmarks from Chrome, Arc and other Chromium browsers.
- **Downloads**: save the film a player streams with one click, or the rest of a season, or a whole
  series, with subtitles. Saved films play in the native player.
- **Rescue**: when a site dies, Cineon finds the film on your other sites and carries on from the
  same second.
- **Together**: share lists with six-letter codes, watch parties with chat, and challenges.
- **Profile**: viewing statistics and a pixel pet.
- **Updates**: Cineon checks for new versions on GitHub and installs them with one click.
